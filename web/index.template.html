管理你的邮箱、外观与通知

外观

自定义登录页和应用中的站点标识。

留空使用默认邮件图标，支持图片链接或站内路径。
填写颜色值或图片地址，留空使用默认背景。

安全

为登录页添加 Turnstile 人机验证。

Site Key 和 Secret Key 都填写后启用；限定域名可防止密钥被复用。

消息通知

收到新邮件时向 Telegram 或 Bark 推送通知。

Telegram

支持私聊 ID 或群组 ID。

Bark

用于推送消息中的邮件详情链接，留空则不附带链接。

附件存储

附件通过 S3 API 存入你的 R2 桶，路径前缀为 mail/att/。

收信过滤

黑名单命中后丢弃；白名单留空表示接收所有地址。

邮件正文存 D1，附件存 R2；超出邮件上限的邮件将被拒收。
